## Product Goal

Give Kerry Local Food Hub staff and volunteers one reliable record of what has arrived, what is held and what is available, so that customers receive only checked goods, shortfalls follow customers' stated preferences, and every allocated item can be traced to its producer and batch.

## Definition of Done

An item is Done only when **all** of these are true:

1. Source file committed; any image export is readable.
2. Names and IDs match the glossary.
3. Reviewer approved the pull request.
4. Linked models still agree; any mismatch is logged as a DEF issue.
